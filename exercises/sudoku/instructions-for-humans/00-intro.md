Exercises in this directory are all based on [Sudoku](https://en.wikipedia.org/wiki/Sudoku).

You can work through them in order in this directory; in that case, after the first exercise, there
will already be some code that the LLM can extend. If you want a fresh start after every exercise, you 
can create a subdirectory per exercise. In that case, you should probably copy the AGENTS.md file to that
subdirectory and adapt it.
