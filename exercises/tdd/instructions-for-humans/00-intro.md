This exercise is about test-driven development.

For the purposes of this exercise, there is a custom `tdd` skill in 
`.opencode/skills/tdd/SKILL.md`. You can take a look at it.

Feel free to modify the skill file. You can find much more elaborate
tdd (and other) skills online. [Example](https://github.com/mattpocock/skills/blob/main/skills/engineering/tdd/SKILL.md)

In opencode, use `/skills` to list the available skills. If you start opencode from the
`exercises/tdd` directory, the `tdd` skill should be listed.
