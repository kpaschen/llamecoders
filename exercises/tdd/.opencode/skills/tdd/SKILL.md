# TDD Skill
Test-driven development.

## Instructions for agent
Use this skill when writing code.

For each feature you are developing, write a test first. The test should fail when the feature has not been
implemented yet. It should pass when the feature has been implemented fully and correctly.

Focus on small tests that verify API boundaries, not implementation details.

Use mocks (pymock) to avoid depending on real backends.

Work one feature at a time. Pick a feature, write the test, then implement the feature, then move on to the next feature.
