Projects should be done by two people.

Once you've found a project partner, create a project description and e-mail Sven with:

* your two names
* the name and description of your project

The description should be precise enough so we can give you early feedback on scoping (we mainly want to make sure you don't
accidentally start a project that is too big to finish within reasonable time). The description also needs to include enough 
information so we (and you) can tell whether you've done what you set out to do. 

The code and tests for your project should be checked into a git repository. You can use your UZH gitlab account; please
include a link to the project in your mail and give [Sven](mailto:sven.helmer@uzh.ch) read access.

In addition to code and tests, please write a short text (1-2 pages is good) on how you used LLM agents during the project.
What worked, what didn't work, what did you do to fix or work around the things that didn't work? 

You have three calendar weeks to work on the project. On Nov 24th, 2026, at 23:59 CET we will check out the repository you gave us and
review your work.

If you have questions or issues during the project, please get in touch!
